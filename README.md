##Description

CyclicList - a C++ STL-style container implementation of a cyclic doubly-linked list. The container supports bidirectional iterators. The implementation follows modern C++17 standards.

##Build

`make`

##Run

`./build/cyclicList`

##Clean

`make clean`

##Rebuild

`make rebuild`
